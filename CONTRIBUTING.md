# Contributing to Hidden Cats: Color Logic

We welcome contributions to improve puzzle generation algorithms, add accessibility options, or enhance visual animations!

### How to Contribute

1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/cool-puzzle-solver`).
3. Ensure all unit and Robolectric tests pass:
   ```bash
   ./gradlew testDebugUnitTest
   ```
4. Verify the debug build succeeds:
   ```bash
   ./gradlew assembleDebug
   ```
5. Commit your changes following standard conventional commits.
6. Open a Pull Request detailing the changes made.
